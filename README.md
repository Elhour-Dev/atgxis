# atgxis

**autoclip** watches live Twitch / YouTube streams, notices when chat explodes, and cuts a clip around each moment.
You review the clips on a local page, export them as vertical 9:16 videos with captions, and can post them to
TikTok / YouTube Shorts / Instagram Reels. Everything runs on your own PC.

```powershell
python -m autoclip doctor          # what is missing
python -m autoclip demo            # offline self-test, must print PASSED
python -m autoclip run <channel>   # watch a stream
python -m autoclip review          # open the review page
```

The full manual (install, settings, posting, Autopilot) is in [autoclip/README.md](autoclip/README.md).
