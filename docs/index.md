# autoclip

autoclip is a free desktop program for Windows (and other systems with Python). It watches **live** Twitch / YouTube streams you choose,
notices when chat reacts strongly, and cuts a clip around each moment. You review the clips on a local web page, trim them, export them as
vertical 9:16 videos, and, only if you choose, send them to your own TikTok, YouTube Shorts or Instagram Reels account.

Everything runs on your own computer. The developer runs no server and receives no data.

## How TikTok is used
* **Login Kit** (`user.info.basic`): you press *Connect TikTok*, approve on TikTok's own page, and the program shows your display name so you can
  see which account is connected.
* **Content Posting API** (`video.upload`): you press *Share* and confirm a dialog showing the file, title and destination. The clip is sent to
  your **TikTok inbox as a draft**. You open TikTok, edit the caption and press Post yourself. Nothing is published automatically.
